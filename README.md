# Fardeen — portfolio (Next.js + Tailwind)

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

Next.js 14 (App Router), Tailwind CSS 3, TypeScript. Fonts via `next/font` (Space Grotesk, Manrope, JetBrains Mono).
Colors and fonts live in `tailwind.config.ts`. Page copy is in `components/*`.
